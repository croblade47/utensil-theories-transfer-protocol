SIZE OF THE GREENHOUSES (shared in advance, NOT in any seed)
  R2 library: 32,768 bytes of training text.  R3-R5 word list: 8,576 entries (R4/R5 add counts; R5 knows 132,894 word pairs).
  R6-R8 tiny transformer: 3,439,680 numbers (about 13.8 MB as float32), far larger than H (84 KB).
  A greenhouse pays off only when it is reused for many messages, like a dictionary both people own.

NOTES
  * Per-verse bits are ideal code lengths -log2(freq/total) of the SAME rounded probabilities the coder
    uses; their sum is within a few bytes of the real seed (see ideal_bits vs seed_bytes in the JSON).
  * WORDS ONLY is accounting, not a stand-alone seed: the decoder would need the markers from elsewhere.
  * Marker word values were computed by the earlier experiments from all verses, held-out ones included;
    kept unchanged because the models were trained with them. In TOTAL every marker is paid for.
  * Each held-out verse is coded with the previous held-out verses (50 verses back) as context, not its
    true neighbours; this is the same for every rung. The 12 groups each restart their context once.
  * Run time 23.9 minutes on 2 threads (torch 2.14.1+cu130, numpy 2.5.3, Python 3.13.16).
