# Contributing to Utensil Theories Transfer Protocol

Thank you for contributing! We welcome community contributions to expand zero-friction physical AI prompt booklets for non-technical users and seniors.

## Guidelines

1. **Accessibility First**: All prompt templates must maintain a 6th-grade reading level, warm empathetic tone, and large-font legibility.
2. **Standard Imposition Layout**: Booklet templates must conform to the 8.5" x 11" 1-sheet zine 2x4 grid imposition sequence (Top row: 8, 1, 4, 5 / Bottom row: 7, 2, 3, 6).
3. **Universal AI Launch Page (Page 2)**: Every booklet must feature Page 2 with the machine-readable Book Code (`H1`..`H8`) and embedded AI startup directives.
4. **Pull Requests**: Submit clean PRs with passing TypeScript compiler checks (`npm run build`).
