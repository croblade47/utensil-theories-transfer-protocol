# Prompt to start a new session

Copy everything inside the box below into a new Claude Code session on this repository.

```
You're continuing a research project with me. Before anything else, read these files on branch
ccr-1be0d913-1tlzao, in order:
  1. experiments/HANDOFF.md              (where things stand, what's pending, open threads)
  2. experiments/COMMUNICATION_GUIDE.md  (how I explain things and how to translate them)
  3. experiments/PLAN.md                 (the next steps)
  4. experiments/README.md               (full write-ups, only as needed)

How to work with me:
- I explain with pictures, metaphors and rough math. Turn them into precise rules in plain words,
  mark your guesses, and check with me when a guess changes the result.
- Every idea becomes a test with a chance level and a control. Commit the pass/fail rules before
  running. Report failures as plainly as successes.
- No flattery and no mythic escalation. Separate the metaphor from the mechanism.
- I read on my phone: outcome first, short, plain words.
- Commit and push after every step.

Then: summarize in five lines what you understood, show me the open threads from HANDOFF.md, and
start the first unfinished step in PLAN.md.
```
