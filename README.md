# Utensil Theories Transfer Protocol Web Studio

[![Vite Build](https://img.shields.io/badge/Vite-6.4.3-blue.svg)](https://vitejs.dev/)

> **Zero-Friction Physical AI Bootstrap Layer & 1-Sheet Zine Studio**

The **Utensil Theories Transfer Protocol** turns physical 8-page zines into self-bootstrapping, vision-readable system prompts for everyday non-technical users and seniors.

---

## 📚 8-Book Category Series Deliverables

Every book features a dedicated **Universal AI Launch Page (Page 2)** with machine-readable Book Codes (`H1`..`H8`), embedded AI startup directives, and standalone printable `.pdf` and `.doc` files:

1. **Book 1: Home & Planning (`H1`)** — Doctor notes, utility bills, Wi-Fi fixes, anti-scam checkers. ([`book1_home_and_planning.pdf`](book1_home_and_planning.pdf))
2. **Book 2: Education & Study (`E2`)** — Antigravity physics levitation, Feynman micro-study sheets, math simplifiers. ([`book2_education_and_study.pdf`](book2_education_and_study.pdf))
3. **Book 3: Entertainment & Games (`G3`)** — Board game rule summarizers, trivia masters, bedtime stories. ([`book3_entertainment_and_games.pdf`](book3_entertainment_and_games.pdf))
4. **Book 4: Small Business (`B4`)** — $50 promos, physical flyer engine, vendor scripts, Google review responders. ([`book4_small_business.pdf`](book4_small_business.pdf))
5. **Book 5: Personal Productivity (`P5`)** — Grocery inflation optimizer, daily Eisenhower matrix, inbox zero assistant. ([`book5_personal_productivity.pdf`](book5_personal_productivity.pdf))
6. **Book 6: Creative Hobbies (`C6`)** — Voice gardening assistant, knitting & crochet guides, woodworking cut lists. ([`book6_creative_hobbies.pdf`](book6_creative_hobbies.pdf))
7. **Book 7: Family & Relationships (`F7`)** — Caregiver doctor visit prep, grandparent conversation starters, care schedules. ([`book7_family_and_relationships.pdf`](book7_family_and_relationships.pdf))
8. **Book 8: Health & Wellness (`H8`)** — Pill schedule formatting, blood pressure logs, gentle seated mobility. ([`book8_health_and_wellness.pdf`](book8_health_and_wellness.pdf))

## 🚀 Getting Started Locally

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production bundle
npm run build
```
